# 우리동네 부동산 히스토리
- URL: https://occidere.github.io/budongsan

## What is this page?
- 부동산 매물 증감, 토지거래허가내역 등을 **상업적 목적이 아닌 개인적으로 확인**하기 위해 만든 페이지입니다

## 기능
### 1. 매물 현황 확인
![image](https://github.com/user-attachments/assets/8d6ceda9-807c-4624-9c63-d169f962b36d)

- 단지별로 매물 현황을 확인할 수 있습니다
- 목록 카드의 단지명을 클릭하면 네이버 부동산 사이트로 연결됩니다
- 목록 카드에 썸네일을 클릭하는 경우 큰 이미지로 볼 수 있습니다
- 여러 부동산에서 등록한 매물인 경우 `동일매물 N건` 텍스트를 클릭하면 모든 부동산 목록을 확인할 수 있습니다
- 삭제 매물의 경우 네이버 부동산에서 내려간 날짜를 기준으로 표기합니다

### 2. 토지거래 허가내역 조회
![image](https://github.com/user-attachments/assets/dc6cc3ad-cccd-456a-a588-19a3e1e1d8a7)

- 서울 25개구의 토지거래 허가내역을 원하는 기간별로 확인할 수 있습니다
- 원하는 단지/지역을 별 아이콘을 클릭하여 상단에 고정/해제할 수 있습니다
- 허가 내역 카드의 주소 (e.g., `강남구 삼성동 16-2`) 를 클릭하면 네이버 지도로 연결됩니다
- 허가 내역 카드 우측 상단의 뱃지 (e.g., 허가 N건, 취하 N건, ..) 를 클릭하면 세부 내역을 확인할 수 있습니다
